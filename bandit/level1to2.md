# Level 1 --> 2

## 문제 개요
홈 디렉터리에 존재하는 `-` 파일에서 다음 레벨의 비밀번호를 획득한다.

## 풀이 과정
1. ssh 서버 접속
2. `ls`로 파일 목록 확인
3. `-` 파일 확인
4. `cat`을 이용하여 `-`이 포함된 파일명을 가진 파일 읽기

## 핵심 개념
- dash(-)는 보통 명령어의 옵션과 argument 로 사용되기 때문에 열기 위해서 다른 설정이 필요하다.

1. touch (파일 생성)
```bash
touch -- -[나머지 파일명]
```

2. cat (파일 읽기)
```bash
# 경로 명시 --> 현재 디렉터리의 파일로 인식
cat ./-[나머지 파일명]

# 입력 리다이렉션 --> 파일 내용을 stdin 으로 전달
cat < -[나머지 파일명]
```

3. cp (파일 복사)
```bash
cp -- -[나머지 파일명]
```

## 보안 관점 분석
- 특수한 파일 이름 (-, --help, *.txt 등)을 이용하여 명령어 오작동을 유도할 수 있다.

## 위험 요소
- 특수한 파일 이름이나 입력 처리 미흡으로 의도하지 않은 명령 실행, 데이터 노출이 발생할 수 있다.

## 대응 방안
- 사용자 입력 검증 수행
- 파일 이름 처리 시 경로를 명시한다.
