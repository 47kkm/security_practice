# Level 9 --> 10

## 문제 개요
`data.txt` 파일은 사람이 읽을 수 없는 binary 데이터로 구성되어 있으며, 해당 파일 내 문자열 중 '=' 문자를 포함하는 값을 찾아 비밀번호를 획득한다.

## 풀이 과정
1. ssh 서버 접속
2. `data.txt` 확인 (바이너리 데이터)
3. `strings` 명령어로 출력 가능한 문자열만 추출
5. `grep "="` 으로 특정 패턴의 문자열 필터링
6. 해당 결과에서 비밀번호 획득 

## 핵심 개념
1. strings
```bash
strings [옵션] [파일명]
```
- 사람이 읽을 수 없는 바이너리 파일에서 텍스트(ASCII)만 추출할 때 사용한다.

2. strings 주요 옵션
```bash
strings -f data.txt
strings -n data.txt
```
- `-f` - 각 문자열 행 앞에 파일 이름을 같이 출력한다.
- `-n` - 문자열의 최소 길이를 정한다.

## 보안 관점 분석
- binary 데이터에서 의미있는 정보를 추출한다.

## 위험 요소
- 바이너리 파일 내부에 민감 정보가 포함될 경우 공격자가 이를 쉽게 추출할 수 있다.
- 개발 코드에 하드코딩으로 비밀번호 등의 민감 정보를 넣어두는 경우 추출될 수 있다.

## 대응 방안
- 민감 정보의 하드코딩 금지
- 환경 변수 사용
- 암호화 저장
