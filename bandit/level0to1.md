# Level 0 --> 1

## 문제 개요
원격 서버에서 ssh 로 접속한 후, 홈 디렉터리에 존재하는 readme 파일에서 다음 레벨의 비밀번호를 획득한다.

## 풀이 과정
1. ssh를 서버 접속
2. `ls` 명령어로 파일 목록 확인
3. `cat` 명령어로 `readme` 파일 출력 및 비밀번호 획득

## 핵심 개념
1. ls
```bash
ls
```
- `ls` 명령어를 통해 현재 디렉토리 내 파일리스트를 확인할 수 있다.
- 옵션
  |옵션|적용|내용|
  |---|---|---|
  | -l |`ls -l`|권한, 소유자, 파일 크기, 수정 시간 등 자세한 정보 출력 (long format)|
  | -a |`ls -a`|숨김 파일까지 모두 보기 (all)|
  | -h |`ls -h`|파일 크기를 KB, MB, GB로 표기|
- `ls -al` 등으로 조합해서 사용도 가능

2. cd
```bash
cd ..
cd /home
```
- `cd` 명령어를 통해 디렉터리를 브라우징 할 수 있다.

3. cat
```bash
cat [타겟파일]
```
- `cat` 명령어를 통해 타겟파일 내용을 확인할 수 있다.

4. du
```bash
du
```
- `du` 명령어를 통해 디스크 사용량(disk usage)를 알 수 있다.
- 옵션
  |옵션|적용|내용|
  |---|---|---|
  |  |`du`|현재 디렉토리 내 모든 파일/디렉터리 용량 출력|
  | -h |`du -h`|KB, MB, GB 단위로 출력|
  | -sh |`du -sh`|총합만(s) KB, MB, GB 단위로(h) 출력|

## 보안 관점 분석
- 시스템에 접근하여 파일 탐색을 통해 내부정보를 수집
- readme 파일 확인을 통한 민감정보 획득 

## 위험 요소
- 서버 내부에 평문(plaintext) 형태로 중요 정보가 저장되어 있을 경우, 공격자가 쉽게 접근하여 해당 정보를 탈취할 수 있다.

## 대응 방안
- 민감 정보는 평문 저장하지 않기
- 접근 권한 제한
- 로그 및 접근 모니터링
