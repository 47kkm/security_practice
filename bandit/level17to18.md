# Level 17 --> 18

## 문제 개요
홈 디렉터리에 `passwords.old`, `passwords.new` 두 개의 파일이 존재한다. 두 파일 간에 변경된 단 한 줄이 다음 레벨의 비밀번호이다.

## 풀이 과정
1. ssh 서버 접속
2. 디렉터리 내 두 개의 파일 확인
3. `diff` 명령어로 두 파일 비교
4. 변경된 라인 확인
5. 두 파일 중 new 파일의 다른 라인이 다음 레벨의 비밀번호

## 핵심 개념
1. diff
```bash
diff [옵션] [파일명1] [파일명2]
```
- 두 파일 사이의 내용을 비교하는 명령어
- 파일 3개 까지 비교가 가능하다.

2. diff 주요 옵션
- `-c` - 파일 간의 차이점 출력
- `-d` - 파일 간의 차이점을 자세히 출력
- `-r` - 디렉터리 간의 차이점 출력 (서브 디렉터리 까지 비교)
- `-i` - 대소문자 차이 무시
- `-w` - 공백 차이 무시
- `-u` - 파일이 변경되는 부분과 근처의 내용 함께 출력

## 보안 관점 분석
- 데이터 변경 감지 (Integrity Monitoring)

## 위험 요소
- 파일 변경을 탐지하지 못하면 침해 사실을 인지하지 못할 수 있다.
- /etc/passwd 변조, ssh 설정 변경, 백도어 추가 등 다양한 방식으로 파일이 변조될 수 있다.

## 대응 방안
- 파일 무결성 모니터링
- 주기적인 diff 비교
- 로그 변경 감지 시스템
- 변경 이벤트 알림
