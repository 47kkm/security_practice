# Level 4 --> 5

## 문제 개요
`inhere` 디렉터리에 존재하는 여러 개의 파일 중 사람이 읽을 수 있는(human readable) 파일을 찾아 다음 레벨의 비밀번호를 획득한다.

## 풀이 과정
1. ssh 접속
2. `inhere` 디렉터리로 이동
3. `ls` 명령어로 파일 리스트 확인
4. `file` 명령어로 각 파일 타입 확인
5. 파일 타입 중 텍스트 파일을 `cat` 명령를 이용해 출력, 비밀번호 획득

## 핵심 개념
1. ASCII text 파일
- ascii 코드로 되어 사람이 직접 읽을 수 있는 파일이다.

2. data 파일
- 일반적으로 응용 프로그램이 사용하는 바이너리 또는 구조화된 파일이다.

3. 파일 형식 확인하기
```bash
file [파일명]
```
- data 파일 결과
  ```bash
  file [파일명1]
  [파일명1]: data
  ```

- ASCII text 파일
  ```bash
  file [파일명2]
  [파일명2]: ASCII text
  ```

## 보안 관점 분석
- 다양한 파일 중 의미있는 데이터를 식별할 수 있다.
- 대량의 데이터 속에서 유의미한 정보만 식별하여 확인한다.

## 위험 요소
- 시스템 내부에 다양한 파일이 존재할 때, 민감 정보가 포함된 파일이 노출되면 이를 쉽게 탈취할 수 있다.

## 대응 방안
- 접근 권한 제한
- 데이터 및 파일 암호화
