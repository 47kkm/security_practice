# 조건에 맞는 파일 찾기

## 조건에 맞는 파일 찾기

(1) 파일 찾기 명령어
```bash
find [경로] [옵션] [조건]
```
- find 명령어와 옵션을 통해 조건에 부합하는 파일을 찾는다.

(2) 주요 옵션
```bash
find [경로] -name
find [경로] -type
find [경로] -size
find [경로] -perm
find [경로] -user
find [경로] -group
find [경로] -mtime
find [경로] -atime
find [경로] -ctime
```
1) name - 파일명으로 찾기
- `-name "*test*"` - 파일명에 test 가 포함되는 파일 찾기
- `-name "*.txt"` - txt 확장자 파일 모두 찾기
- `-name "test*"` - test 로 시작하는 파일 모두 찾기
- `-name "test"` - 파일명이 test인 파일 찾기

2) type - 타입으로 찾기
- `d` - 디렉토리 찾기
- `t` - 일반 파일 찾기
- `l` - 심볼릭링크 파일 찾기

3) size - 크기로 찾기
- `empty` - 빈디렉터리 이거나 크기가 0인 파일 찾기
- `-size 1024c` - 크기가 1000바이트인 파일 찾기
- `-size +1024c` - 크기가 1024바이트보다 큰 파일 찾기
- `-size -1024c` - 크기가 1024바이트보다 작은 파일 찾기
- `-size +512c -size -1024c` - 512바이트보다 크고 1024바이트보다 작은 파일 찾기
- `b`: 블록단위
- `c`: byte
- `k`: kbyte
- `w`: 2byte 워드

4) perm - 권한으로 찾기
- `-perm 644` - 644 권한의 파일 찾기
- `-perm -644` - 644 권한을 포함하는 파일을 찾는다.
- `-perm +644` - 644 권한 중 일부만이라도 포함하는 파일을 찾는다.
- `-perm -4000` - setuid 가 설정된 모든 권한의 파일 찾기
- `-perm -2000` - setgid 가 설정된 모든 권한의 파일 찾기

5) user - 해당 유저에게 속한 파일 찾기
- `-user root` - root 소유의 파일 찾기

6) group - 해당 그룹에 속한 파일 찾기
- `-group root` - root 그룹 소유의 파일 찾기

7) mtime - n일 기준 수정된 파일 찾기
- `-mtime -7` - 7일 이내 수정된 파일 찾기 (7일 전 ~ 현재)
- `-mtime 7` - 7일 전 하루 동안 수정된 파일 찾기 (8일 전 ~ 7일 전)
- `-mtime +7` - 7일 전보다 과거에 수정된 파일 찾기

8) atime - n일 기준 액세스된 파일 찾기
- `-atime -7` - 7일 이내 액세스된 파일 찾기 (7일 전 ~ 현재)
- `-atime 7` - 7일 전 하루 동안 액세스된 파일 찾기 (8일 전 ~ 7일 전)
- `-atime +7` - 7일 전보다 과거에 액세스된 파일 찾기

9) ctime - n일 이내에 속성이 변경된 파일 찾기
- `-ctime -7` - 7일 이내 속성이 변경된 파일 찾기 (7일 전 ~ 현재)
- `-ctime 7` - 7일 전 하루 동안 속성이 변경된 파일 찾기 (8일 전 ~ 7일 전)
- `-ctime +7` - 7일 전보다 과거에 속성이 변경된 파일 찾기
