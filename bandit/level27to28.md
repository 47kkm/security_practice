# Level 27 --> 28

## 문제 개요
`bandit27` 계정의 비밀번호를 이용해 주어진 깃 저장소를 클론하고 다음 레벨 비밀번호를 획득한다.

## 풀이 과정
1. `git clone` 명령어를 이용하여 저장소 클론
2. 로컬에서 클론한 디렉터리에 접근
3. `README` 파일 확인 및 비밀번호 획득

## 핵심 개념
1. git 클론
```bash
git clone [repository 주소]
```
- git 저장소를 로컬에 클론한다.

```bash
git clone ssh://[user]@[host]:[port]/[path]
```
- ssh 인증으로 저장소에 접근하여 클론한다.

## 보안 관점 분석
- 소스 코드 내 민감 정보 노출
- 서버를 뚫지 않아도 git 에 업로드된 소스 코드에 민감 정보가 저장되어 있으면 쉽게 탈취 가능하다.

## 위험 요소
- 개발 시 민감 정보를 소스코드에 저장하여 함께 커밋하면 클론하여 쉽게 확인할 수 있다.

## 대응 방안
- 코드 내 민감 정보 하드코딩 금지
- 민감 정보의 경우 환경 변수 사용
- 가능한 경우 `private` 저장소 사용
