# Level 32 --> 33

## 문제 개요
`bandit32` 계정에 접속하면 일반적인 쉘이 아니라 특수한 제한된 쉘(upper case shell) 이 실행된다.
이 쉘은 입력을 대문자로 변환하여 명령 실행을 방해한다.
이를 우회하여 정상 쉘을 실행하고 비밀번호를 획득한다.

## 풀이 과정
1. ssh 서버 접속
2. 명령어 실행시 모든 명령어가 대문자로 바뀌어 실행이 불가함을 확인
3. 대문자로 변경되어도 영향이 없는 명령어 사용 `$0`
4. `whoami` 명령어 사용하여 계정 확인
5. 다음 레벨 비밀번호 획득

## 핵심 개념
1. 제한된 셸 우회하기
- 대문자 변환을 통해 명령어 실행을 막았을 뿐, 실행을 막은 것은 아니므로 우회가 가능한 명령어를 찾는다.

2. $0
- 현재 실행 중인 셸 이름
- 명령어로 실행하면 현재 셸을 다시 실행한다.

## 보안 관점 분석
- 입력 필터(대문자 입력)를 통한 보안을 우회하기

## 위험 요소
- 특정 입력으로 입력 필터를 우회하여 셸을 획득할 수 있다.

## 대응 방안
- 화이트리스트 제어로 허용된 명령어만 실행할 수 있도록 한다.
- 입력 검증 강화
- 최소 권한 적용
