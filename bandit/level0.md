# Level 0

## 문제 개요
주어진 id, host 와 port 번호를 이용하여 ssh 원격 서버에 접속한다.

## 풀이 과정
1. ssh를 이용하여 원격 서버 접속

## 핵심 개념
1. SSH (Secure Shell)
- 네트워크를 통해 원격 서버에 안전하게 접속할 수 있도록 하는 프로토콜
- 모든 통신이 암호화되어 전송된다.

2. key 를 이용해 접근하기
```bash
ssh -i [key 파일 경로] [user]@[host]
```
- `-i` 옵션을 통해 key 파일로 로그인한다.
  - `key 파일 경로`에 .pem 파일 로컬 경로를 입력한다. 
- `user`는 서버의 계정 이름이다.
- `host`는 접근하고자 하는 서버 주소 (ip, 도메인) 이다.
- sshd_config 설정에 `PasswordAuthentication` 가 no 로 설정되어 있으면 패스워드 로그인은 불가능하고 key 로그인만 가능하다.
- 이때 접근 포트는 기본적으로 22번 이다.

3. password 를 이용해 접근하기
```bash
ssh [user]@[host]
```
- `host` 서버에 `user`로 로그인한다.
- 이때 접근 포트는 기본적으로 22번 이다.
- 이후 나오는 패스워드 입력 화면에서 패스워드 입력 후 로그인 한다.

4. 지정된 포트로 password 이용해 접근하기
```bash
ssh -p [지정된 포트] [user]@[host]
```
- `host` 서버에 `user`로 로그인한다.
- [지정된 포트] 에 포트를 입력한다.
- 이후 나오는 패스워드 입력 화면에서 패스워드 입력 후 로그인 한다.
