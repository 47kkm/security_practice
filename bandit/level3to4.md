# Level 3 --> 4

## 문제 개요
`inhere` 디렉터리 내에 숨겨진(`hidden`) 파일에서 다음 레벨의 비밀번호를 획득한다.

## 풀이 과정
1. ssh 서버 접속
2. `inhere` 디렉터리로 이동
3. `ls` 실행 시 파일이 보이지 않음을 확인
4. `ls -a` 옵션으로 숨김 파일 확인
5. `.hidden` 파일을 찾고, `cat`을 이용해 파일 확인

## 핵심 개념
1. 숨김 파일
- 리눅스에서 파일이름이 `.`로 시작하면 기본 `ls` 명령어에서는 표시되지 않는다.

2. ls -a
```bash
ls -a
```
- 파일 목록을 확인하는 `ls`명령어에 `-a` 옵션을 이용하여 숨겨진 파일을 확인한다.

## 보안 관점 분석
- 표면적으로 보이지 않는 파일/정보를 찾아낸다.
- 파일을 숨김 처리 하여도 보안이 확보되지는 않는다.

## 위험 요소
- 중요 정보가 숨김 파일에 저장되어 있어도 공격자가 쉽게 발견하여 해당 정보를 탈취할 수 있다.

## 대응 방안
- 접근 권한 제한
- 중요 파일은 암호화
