# Level24 --> 25

## 문제 개요
로컬 서버의 특정 포트에서 서비스가 실행중이며, `bandit24`의 패스워드와 `4자리 핀코드`를 입력하여 인증을 수행한다.
핀코드는 0000 - 9999 범위의 4자리 숫자 중 하나 이다. 무차별 대입 공격(Brute Force Attack)을 통해 다음 레벨의 비밀번호를 획득한다.

## 풀이 과정
1. ssh 서버 접속
2. 서비스포트 메시지 전송 및 확인을 통해 패스워드와 핀코드를 넘기는 구조 확인 (패스워드 + 공백 + 핀코드)
3. /tmp/****/ 경로에 sh 파일 생성
4. 0000 부터 9999까지의 핀코드를 대입해보는 스크립트 코드 작성
5. 다음 레벨의 비밀번호 획득

## 핵심 개념
1. Brute Force 공격
- 가능한 모든 값을 시도하여 정답을 찾는 방식
- 대입하는 방식을 스크립트로 자동화하여 수행하여 효율성을 높인다.

## 보안 관점 분석
- 인증 시스템의 취약점
- 인증 흐름 분석 및 스크립트를 통한 자동화를 이용한 공격

## 위험 요소
- 핀코드의 범위가 너무 작아서 무차별 대입 공격으로 쉽게 크래킹 가능
- 보안을 위해 키공간을 크게 가져가야 한다.
- 시도 횟수 제한이 없으면 무한 시도가 가능하고, 언젠가는 크래킹 가능하다.

## 대응 방안
- 실패 시도 횟수 제한
  - N번 실패 시 로그인 차단, 계정 잠금
- 복잡한 인증 방식 사용
  - 키공간을 크게 사용
- CAPTCHA 등의 툴을 이용한 자동화 공격 방지
- 로그 모니터링을 통한 비정상적인 반복 시도 탐지
