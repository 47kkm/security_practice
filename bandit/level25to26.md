# Level 25 --> 26

## 문제 개요
제공된 키파일(`bandit26.sshkey`)를 사용하여 다음 레벨에 접속한다.
로그인 시 `/bin/bash` 셸이 아닌 다른 셸이 실행되어 즉시 종료된다.
이를 우회하여 다음 레벨의 비밀번호를 획득한다.

## 풀이 과정
1. `bandit25` ssh 서버 로그인
2. `bandit26.sshkey` 파일 확인
3. 해당 파일을 이용하여 ssh 로그인
  - `bandit26@localhost` 로 시도했을 때 로그인이 되지 않음
  - `scp` 명령어를 이용해 key 파일을 내려받고 로그인 하려 했으나 해당 명령어 사용 불가
  - `cat`으로 파일을 읽어 메모장을 이용해 로컬에 key 파일 수동 생성
4. `bandit26` ssh 로그인 시도 시 메시지와 함께 접속이 바로 종료된다.
5. `bandit25` 계정으로 다시 로그인
6. `bandit26`의 로그인셸 정보를 확인하기 위해 `/etc/passwd` 파일 읽기
7. `/etc/passwd` 내 `bandit26` 계정의 로그인셸 확인 후 `cat` 을 이용해 해당 파일 읽기
8. `bandit26`의 로그인셸 파일인 `/usr/bin/showtext`를 읽어보면 로그인 시 `~/text.txt` 파일이 `more` 모드로 실행되고 있음을 알 수 있음
9. `more`의 특성을 이용하기 위해 터미널 화면을 작게 만들어서, 출력 내용이 한 페이지에 전부 나오지 않도록 조정
10. key를 이용해 `bandit26` 로그인 시도
11. `--More--`확인 및 `v`명령어를 이용해 vi 편집 모드 설정
12. `vim` 에서 셸 탈출 (우회 로그인)
13. `/etc/bandit_pass/bandit26` 파일을 읽어 비밀번호 획득

## 핵심 개념
1. 제한된 셸 (Restricted Shell)
- 사용자가 특정 프로그램만 실행 가능하도록 제한
- 해당 문제 상황에서는 `showtext` 파일만 실행되도록 설정

2. more (more Unix pager)
```bash
# hugefile.txt 를 more 방식으로 읽음
cat hugefile.txt | more

# hugefile.txt 를 more 방식으로 실행
exec more ~/text.txt
```
- 긴 텍스트를 한 화면씩 끊어서 보여주는 프로그램
- 터미널은 출력이 길어지면 위로 쭉 흐르기 때문에 중요한 내용도 쉽게 놓친다. 따라서 pager 를 이용해 사용자가 페이지를 넘기도록 설정할 수 있게 한다.
- 조작법
  - `Enter`: 한 줄 아래
  - `Space`: 다음 페이지
  - `q`: 종료
- 상태
  - 실행 중: 텍스트가 흐름
  - 멈춘 상태(`--More--`): 키 입력 가능
- `vim` 실행 기능
  - 멈춘 상태에서 `v`를 누르면 `vim text editor`가 실행된다. (편집 기능)

3. `vim`에서 외부 셸 실행하기
```bash
# vim 설정 변경 --> vim 이 사용할 셸을 /bin/bash 로 변경
:set shell=/bin/bash

# 실행 명령 --> vim 에서 빠져나가, 방금 설정한 셸을 실행
:shell
```

## 보안 관점 분석
- 제한된 환경에서 탈출 취약점을 가질 수 있다.
- `more`이 `vim` 기능을 제공하고 `vim`이 셸 실행기능을 제공하여 제한된 계정을 탈출할 수 있는 가능성을 제공한다.

## 위험 요소
- 제한된 셸만으로는 보안을 보장할 수 없다.
- 인터랙티브 프로그램을 활용하여 제한된 상황을 탈출할 수 있다.

## 대응 방안
- 인터랙티브 프로그램 제한
  - vim, less 등 사용 제한
- ForceCommand 사용하여 특정 명령만 실행하도록 강제
- rbash (restricted shell) 강화
  - 제한된 기능만 제공하는 bash
  - cd, 환경변수 변경 등 금지, 다른 쉘 실행 제한 등
- `no-pty` 설정
  - 사용자에게 `tty` (입력 가능한 터미널)을 할당하지 않음으로써 인터랙티브 프로그램 활용을 막는다.
  - 필요 없는 계정에서 no-pty
    - ec2-user, admin 등 서버 작업을 위한 운영 계정을 허용
    - CI/CD, 배치작업, 로그 수집 계정 등 직접 조작할 필요가 없는 계정들은 차단
