# Level 23 --> 24

## 문제 개요
`/etc/cron.d/` 경로에 있는 파일을 확인하여 어떤 명령이 수행될지를 확인한다. 셸스크립트를 작성하여 다음 레벨의 비밀번호를 획득한다.

## 풀이 과정
1. ssh 서버 로그인
2. `/etc/cron.d/` 경로 이동
3. `ls` 명령어를 통해 파일 리스트 확인 및 다음 레벨 비밀번호 관련 파일 확인
4. `cat`을 이용해 해당 파일 읽고, 예정된 스케줄 작업 확인하기
5. 스케줄 작업시 `/var/spool/bandit24/foo` 디렉터리 내 스크립트가 모두 실행된다는 점을 이용
6. 해당 스케줄 작업이 `bandit24` 사용자 권한으로 실행된다는 점을 이용
7. `bandit24` 사용자가 읽기 권한을 갖고 있는 해당 계정 비밀번호 파일을 읽어, `/tmp/***` 에 텍스트파일로 저장하는 스크립트 파일을 작성하여 `/var/spool/bandit24/foo` 디렉터리로 복사
8. `bandit24` 계정 권한으로 해당 디렉터리내 스크립트 파일들이 실행되어 다음레벨 비밀번호 획득

## 핵심 개념
1. cron 실행
- cron 이 실행될때는 해당 설정 파일 소유주 권한으로 실행된다.

2. 권한 상승
- 낮은 권한으로 작성한 스크립트를 높은 권한으로 실행

## 보안 관점 분석
- 쓰기(w)가 가능한 경로에 파일 쓰기를 통해 권한 상승 및 상승된 권한으로 파일 실행
- 코드를 주입하고, 자동 실행 시킴으로써 권한 탈취
- 스크립트 삽입 --> cron 실행 --> 권한 탈취

## 위험 요소
- 실행 디렉터리(여기서는 `/var/spool/bandit24/foo`)에 쓰기가 가능하면 위험하다.

## 대응 방안
- 실행 디렉터리 권한 제한 (`chmod 700`)
- cron 실행 전에 파일 소유자 검증
- 허용된 파일만 실행하도록 whitelist 처리
