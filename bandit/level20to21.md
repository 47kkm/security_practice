# Level 20 --> 21

## 문제 개요
home 디렉터리에 setuid 바이너리 파일이 있으며, 해당 파일을 이용하여 사용자가 임시로 설정한 localhost 포트에 연결할 수 있다. 임시 포트에 연결 후 현 사용자 비밀번호를 전송하면, 다음 레벨의 비밀번호를 획득한다. 

## 풀이 과정
1. ssh 서버 로그인
2. 디렉터리 내 `./suconnect` 파일 실행
3. 포트번호를 `argument`로 받아 연결하는 파일임을 알 수 있음 
4. 새로운 터미널에 `bandit20` 계정으로 로그인
5. 새로운 터미널에 `nc -lvp [포트번호]` 명령어를 이용해서 임시 포트 오픈
6. 기존 터미널에서 `./suconnect [임시 오픈한 포트번호]` 를 이용하여 연결
7. 새로운 터미널에서 비밀번호 전송 및 신규 비밀번호 응답 획득 

## 핵심 개념
1. 서버와 클라이언트
- `nc -lpv`를 통해 리스닝 서버를 생성 (대기)
- 클라이언트에서 `suconnect` 파일 실행 (접속)

2. 포트 리스닝
```bash
nc -lvp 55555
```
- 해당 포트에서 연결을 기다린다.
- 연결 후 데이터 송수신이 가능하다.
- 즉 `suconnect` 파일은 `포트연결 + 데이터 전송`을 수행하는 서비스이다.

## 보안 관점 분석
- 서비스간 통신 구조의 이해
- 서버에서 클라이언트로 연결 가능
- 외부 접근이 제한된 환경임에도, 내부 시스템이 먼저 연결을 시도하도록 유도하여 데이터 획득

## 위험 요소
- 내부 서버에서 외부로 연결하면 데이터 유출이 가능하다.
- 아웃바운드 트래픽의 경우 방화벽을 잘 설정하지 않는 경우가 많기 때문에 역방향(서버 --> 클라이언트)의 연결을 통해 공격이 발생할 수 있다.
